Доска в стиле Trello: 3 фиксированные колонки, карточки с drag & drop, редактор, сохранение в LocalStorage.

Исходные задания — в [TASKS.md](./TASK.md).

## Возможности

- 3 колонки: TODO, In Progress, Done (фиксированы).
- **Создание карточки** — клик «+ Add another card» сразу открывает модальный редактор со всеми полями.
- **Редактирование** — клик по карточке или по иконке ✎ открывает тот же редактор с заполненными полями.
- **Удаление** — иконка ✕ в правом верхнем углу карточки (появляется при ховере).
- **Поля карточки**:
  - заголовок (обязателен);
  - описание;
  - цвет фона (палитра swatch-ей);
  - чек-лист (добавление/удаление пунктов, чекбоксы);
  - изображения (через `<input type="file">` или drag & drop прямо в модалку, лимит 1 MB на файл).
- **Чек-лист на карточке** — под счётчиком `✓ N/M` выводится полный список пунктов с интерактивными чекбоксами:
  - клик по чекбоксу переключает `done` в состоянии и сохраняет в `localStorage`;
  - выполненные пункты зачёркнуты и серые;
  - клик по чекбоксу **не** открывает редактор и **не** запускает drag.
- **Drag & Drop** — карточки перетаскиваются внутри и между колонками:
  - на месте вставки показывается плейсхолдер высотой с карточку;
  - позиция «до/после» определяется по положению курсора (по центру карточки);
  - у перетаскиваемой карточки курсор `grabbing` и полупрозрачность.
- **Сохранение состояния** в `localStorage` — DOM строится из сохранённого состояния.
- **Миграция старых данных** — карточки `{ id, text }` автоматически конвертируются в `{ id, title, description, color, images, checklist }`.

## Стек

- JavaScript (ES2020+), без фреймворков
- Webpack 5 + `babel-loader` + `css-loader`
- Нативный HTML5 Drag & Drop API
- `localStorage` для персистентности
- ESLint (flat config)
- Yarn (в репозитории `yarn.lock`, `package-lock.json` в `.gitignore`)

yarn install
yarn start      # http://localhost:8080
